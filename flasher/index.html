ControlBlock Flasher

Install the ControlBlock firmware on a Waveshare ESP32-S3-Touch-LCD-4.3, straight from the browser.

This browser can't flash devices: use Chrome or Edge on a desktop computer. Flashing needs a secure (HTTPS) page. Firmware version: loading...

Steps

  1. Use Chrome or Edge on a desktop computer (Windows, macOS or Linux). Other browsers can't reach serial ports.
  2. Plug the board into the computer by its native USB port (labelled USB, not UART). No driver is needed.
  3. Put the board in download mode: hold BOOT, press and release RESET, then release BOOT.
  4. Click Install above and pick the board's port.
  5. Leave "Erase device" unticked to keep the Wi-Fi settings and the stored layout. Ticking it wipes both (a fresh install).
  6. When it's done, press RESET on the board. The firmware starts and the port goes away: that's normal (the firmware uses the native port for itself).

Then set it up

With Node.js 24 and git installed, check the board from a terminal:

npx github:toptensoftware/ControlBlock#cli info

The same command sets up Wi-Fi and uploads layouts: see the ControlBlock README.

Without this page

Download the bins from the GitHub Releases page and flash them with Espressif's esptool (download mode as above; replace COM5 with the board's port):

esptool --chip esp32s3 -p COM5 write-flash 0x0 bootloader.bin 0x8000 partition-table.bin 0x10000 controlblock-<version>.bin

These three parts keep the settings and the layout. The release's single -full.bin image is a fresh install: it wipes the Wi-Fi settings.
